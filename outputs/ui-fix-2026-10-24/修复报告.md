# 品牌标识问题修复报告（2026-10-24）

用户截图反馈三个问题，全部为前端显示问题，已定位根因并修复。

## 问题一：顶栏左上角品牌标识四个角被遮盖

### 现象

顶栏标识呈方块，但发丝边框的**四个角被切掉**，看起来像一张破贴纸。

### 根因

`web/src/App.module.css` 的 `.navBrandMark` 给 SVG 加了：

```css
border-radius: 6px;
box-shadow: 0 1px 2px rgba(0, 0, 0, 0.18);
/* 注释：The tile is a rounded square with its own dark gradient. */
```

这段规则连同注释都是**深蓝渐变瓷砖时代**的遗留。母图 `build/icon.svg` 自己的注释已经写死了相反的规则：

> No gradient, no shadow, no rounded corners — **the square edge and the hairline are the style.**

关键在于**圆角不是样式而是裁切**：

| 量 | 数值 |
|---|---|
| 母图发丝框 | `x=26 y=26 width=460 height=460`（512 网格） |
| navbar 显示尺寸 | 26px |
| 框距边实际距离 | 26 / 512 × 26 ≈ **1.3px** |
| 圆角切除区半径 | **6px** |

6px 的圆角切除区完全覆盖了 1.3px 处的发丝框 → 四角被裁掉。

### 修复

删除 `border-radius` 与 `box-shadow`（含 ≤640px 媒体查询中的 `border-radius: 7px`），让标记回到母图原样的方边，由卡片自己的发丝框描边。

对比：修复前四角残缺 → 修复后发丝框四角完整。

## 问题二：知识库智能对话前不该有品牌标识

### 现象

「知识库智能对话」标题前有一个品牌标识方块（套在蓝色圆角底上），与下面的灯泡图标、整个页面视觉都不搭。

### 修复

删除 `HomeKnowledgeAssistant.tsx` 头部整块 `headerIcon` 容器（连带无用的 `.headerLeft` / `.headerIcon` CSS 规则一并清理）。

## 问题三：品牌标识过多

### 统计

全站 `BrandMark` 使用点共 3 处：

| 位置 | 处理 |
|---|---|
| `App.tsx` navbar | **保留** —— 这是应用身份本身 |
| `HomeKnowledgeAssistant` 助手头部 | 删除（见问题二） |
| `HomeKnowledgeAssistant` AI 消息头像 | 改为文本 `"AI"` |

消息头像原本用户侧是 `"Me"` 文字、AI 侧是品牌标识，不对称；且 16px 下母图发丝框本就是亚像素级别。改为 `"AI"` 后两侧对称，且页面级品牌标识计数降为 1。

### 验证

6 个主页面逐一统计 `svg rect[fill="#F5F0E4"]` 数量，结果全部为 **1**（仅 navbar）：

```
/=1  /dashboard=1  /knowledge=1  /review=1  /search=1  /settings=1
```

## 守卫测试

`BrandMark.test.tsx` 新增两个用例，沿用项目既有的「node:fs 读样式表」手法（CSS module 在 vitest 不求值，DOM 断言看不见这些规则）：

1. **`.navBrandMark` 规则体不含 `border-radius` / `box-shadow`** —— 防止圆角复活再次切掉四角。
2. **`HomeKnowledgeAssistant.tsx` 源码不含 `BrandMark`** —— 防止品牌标识在助手页复现。
